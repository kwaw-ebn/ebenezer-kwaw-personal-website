Loan Default Prediction Platform

By Ebenezer Kwaw · 25 September 2026 · Portfolio ML prototype
View original report ↗View portfolio ↗

A machine-learning prototype for estimating loan-default risk through an interactive decision-support interface.

Project typePortfolio ML prototype
DisciplineMachine Learning and Fintech
Primary evidenceOriginal project report retained on Google Drive

The challenge

Manual credit-risk assessment may be slow, inconsistent and difficult to scale across digital lending workflows.

The strategy

Use a classification model to generate a risk probability while presenting performance and limitations transparently to a human decision-maker.

My contribution and execution

  • Prepared applicant data and trained classification models.
  • Reviewed discrimination through ROC analysis and errors through a confusion matrix.
  • Built a Streamlit interface for interactive assessment.
  • Defined future work around explainability, API integration and monitored deployment.

Tools and methods

Python, scikit-learn, Pandas, NumPy and Streamlit

Outcome, evidence and limitations

The source deck reports 87.5% accuracy, 85% precision, 90% recall and an 87% F1 score on its evaluation setup. These figures need reproducible validation, fairness review and out-of-sample testing before the model could support real lending decisions.
